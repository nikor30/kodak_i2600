# kodak_i2600

Open-source Raspberry Pi support for the **Kodak i2600** document scanner
(USB `040a:601d`): headless scanning into **Paperless-ngx**, driven by the
scanner's own buttons and panel.

- Plan & structure: [`PLAN.md`](PLAN.md)
- Current status: [`memory/STATUS.md`](memory/STATUS.md)

Reverse engineering here is for interoperability only. No vendor binaries or
code are stored in this repository.
