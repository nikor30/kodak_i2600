Profiles

A profile says how a stack is scanned and filed. The display text is shown on the scanner (plain letters and digits; up to about 30 characters appear large).

Changes take effect when saved: the station restarts with the new settings (about 15 seconds). A copy of the configuration from before the first change is kept as config.yaml.bak-web.
