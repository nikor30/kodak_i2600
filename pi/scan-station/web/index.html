Network share (SMB)

A Windows or NAS share that profiles can save their PDFs to. The password is stored on the scan station and never shown again.

E-mail

A mail server that profiles can send their PDFs through. The password is stored on the scan station and never shown again.

Buttons

The arrow buttons on the scanner choose a function number; Start scans with the profile set here. The display shows the profile's text next to the number.

After the idle time the station sends nothing more to the scanner, so the scanner can go to standby by itself; any button or new paper ends the rest. The clock on the display stops being shown then.
